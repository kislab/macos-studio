## macOS Studio 1.2.2 — Update-Test

Ab dieser Version sucht die App direkt bei jedem Start im Hintergrund nach Updates. Wenn ein Update verfügbar ist, bietet sie die Installation direkt in der App an. Anschließend prüft sie weiterhin alle sechs Stunden.

Apps ab Version 1.2 erkennen das signierte Update beim nächsten automatischen Check und bieten die Installation direkt in der App an. Bei älteren Versionen gilt noch der bisherige Prüfzyklus von sechs Stunden. Alternativ lässt sich die Erkennung sofort über **macOS Studio → Nach Updates suchen …** testen.

Nach erfolgreicher Installation zeigt **Über macOS Studio** die Version **1.2.2** (Build **5**).

Universal-App für Intel und Apple Silicon ab macOS 13. Update-Archiv und Feed sind Ed25519-signiert; die App ist weiterhin ad-hoc signiert und nicht Apple-notarisiert.
