## OS Studio 1.8.7 — Chrome extensions

- **Extras › Chrome:** The self-made extension “Basel Begleitschein” is included. One click places it in a fixed folder that Chrome loads it from; a guide walks through the installation.
- **Updating:** If the folder holds an older version, OS Studio updates it with one click. Export as ZIP is available at any time.

Universal for Intel and Apple silicon, macOS 13 or later. Build 57.
