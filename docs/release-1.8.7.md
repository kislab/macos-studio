## OS Studio 1.8.7 — Chrome-Erweiterungen

**[App herunterladen (DMG)](https://github.com/kislab/macos-studio/releases/download/v1.8.7/OS-Studio-1.8.7-Universal.dmg)**

- **Extras › Chrome:** Die eigene Erweiterung „Basel Begleitschein“ ist enthalten. Ein Klick legt sie in einem festen Ordner ab, aus dem Chrome sie lädt; eine Anleitung führt durch die Installation.
- **Aktualisieren:** Enthält der Ordner eine ältere Version, aktualisiert OS Studio ihn mit einem Klick. Export als ZIP ist jederzeit möglich.

Universal für Intel und Apple Silicon, ab macOS 13. Build 57.
