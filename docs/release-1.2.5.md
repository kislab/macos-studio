## macOS Studio 1.2.5 — Update-Test

**[App herunterladen (DMG)](https://github.com/kislab/macos-studio/releases/download/v1.2.5/macOS-Studio-1.2.5-Universal.dmg)**

Dieses Release testet die automatische Update-Erkennung. Die Funktionen entsprechen Version 1.2.4; Version und Build wurden erhöht.

Zum Testen die installierte Version 1.2.4 vollständig beenden und neu starten. Wenn das Update erkannt wird, bietet die App Version 1.2.5 an. Bei bereits aktueller Version erscheint bei der automatischen Prüfung kein Dialog.

Version 1.2.5, Build 8. Universal für Intel und Apple Silicon ab macOS 13. Die ZIP-Datei dient den In-App-Updates, SHA256SUMS.txt enthält die Prüfsummen. Updates und Feed Ed25519-signiert; App ad-hoc signiert, nicht Apple-notarisiert.
