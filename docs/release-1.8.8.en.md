## OS Studio 1.8.8 — GSX appointments → Calendar

- **Extras › Chrome:** New extension “GSX Termine → Kalender”. It reads appointments from GSX and exports them with first and last names to Apple Calendar.
- Creating the folder, updating and exporting as ZIP work like for “Basel Begleitschein”; the guide covers both extensions.

Universal for Intel and Apple silicon, macOS 13 or later. Build 58.
