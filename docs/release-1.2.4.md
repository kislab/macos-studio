## macOS Studio 1.2.4 — Update-Prüfung beim Start

**[App herunterladen (DMG)](https://github.com/kislab/macos-studio/releases/download/v1.2.4/macOS-Studio-1.2.4-Universal.dmg)**

Die App prüft nach dem Öffnen des Fensters im Hintergrund auf Updates. Nur eine neuere Version wird angeboten; bei aktueller Version erscheint kein Dialog. Laufende Vorgänge werden vor der Startprüfung abgewartet. Die Prüfung startet einmal pro App-Start, sofern automatische Prüfungen aktiviert sind.

Für ältere installierte Versionen einmal „macOS Studio → Nach Updates suchen …“ verwenden oder die neue App aus der DMG nach Programme kopieren.

Die ZIP-Datei dient den In-App-Updates; SHA256SUMS.txt enthält die Prüfsummen. Universal für Intel und Apple Silicon ab macOS 13. Build 7. Ed25519-signierte Updates, App weiterhin ad-hoc signiert und nicht notarisiert.
