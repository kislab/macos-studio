## OS Studio 1.8.3 — installierte Version erkennen

**[App herunterladen (DMG)](https://github.com/kislab/macos-studio/releases/download/v1.8.3/OS-Studio-1.8.3-Universal.dmg)**

- **Installer-Liste:** Der Build, der auf deinem Mac läuft, ist grün als „Läuft bereits auf diesem Mac“ markiert.
- Builds derselben Version für andere Macs heißen jetzt „Version … schon auf diesem Mac · dieser Build ist für andere Macs“ statt „Nicht für diesen Mac“. Ältere Builds für andere Macs zeigen „Neuere Version schon auf diesem Mac“.

Wer 1.8.1 oder älter nutzt, installiert einmal von Hand aus der DMG (neuer Update-Schlüssel seit 1.8.2). Universal für Intel und Apple Silicon, ab macOS 13. Build 53. Ed25519-signierte Updates; App ad-hoc signiert, nicht notarisiert.
