## macOS Studio 1.2.7 — Frische Update-Abfrage

**[App herunterladen (DMG)](https://github.com/kislab/macos-studio/releases/download/v1.2.7/macOS-Studio-1.2.7-Universal.dmg)**

Jede Update-Prüfung verwendet eine neue Abfragekennung, damit zwischengespeicherte Feed-Antworten neue Releases nicht vorübergehend verbergen. Die Ed25519-Signaturprüfung bleibt verpflichtend. Automatische Prüfungen bleiben ohne Dialog, solange kein neueres Update gefunden wird.

Direkt an der installierten Version 1.2.5 reproduziert: Die manuelle Suche meldete zunächst „aktuell“. Mit frischer Feed-Abfrage erschien das Angebot für 1.2.6.

Universal ab macOS 13, Intel und Apple Silicon. Build 10. ZIP für In-App-Updates, SHA256SUMS.txt für Prüfsummen. App ad-hoc signiert, nicht notarisiert.
